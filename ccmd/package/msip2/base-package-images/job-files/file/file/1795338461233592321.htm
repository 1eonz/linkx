张家口市公安局

派出所处置人员失踪警情工作规范

一、派出所职责

协助报警人查找疑似被侵害或者无故下落不明人员的报警求助，全力开展人员查找、侦办处置等工作，坚决维护人民群众生命安全。

二、派出所处置要求

(一)详细询问并登记失踪人员身份信息、失踪时间、失踪地点、失踪原因、通联方式及状态、体貌特征、精神状况、近期照片等情况，核实登记报警人的身份资料、联系方式、与失踪人员的关系等情况，并初步判断警情性质。

（二）通过查询视频监控、车脸、人脸等手段来确定失踪人员行动轨迹，并沿轨迹实地进行人员查找；

（三）对于系统上无法直接查到行动轨迹的未成年人、老年人以及有可能被侵害人员，由处置民警上报技侦通过手机定位确定位置；

（四）处置民警及时将失踪人员信息流转至综合指挥室，对接今日头条发布寻人信息；

（五）针对搜寻范围较大或搜寻难度较高时，及时联动蓝天救援队等社会组织共同参与失踪人员的搜寻、救助工作；

（六）失踪人员若有受伤情况，处置民警及时联系医院一同前往处置；若失踪人员被找到时已无生命体征，参照《派出所非正常死亡事件工作规范》进行处置；

(五)若暂时无法获得失踪人员相关信息，告知报警人有新的线索或者找到失踪人员时，应当及时报告。

（六）建立本辖区人员失踪警情、案件定期统计分析研判，及时对区域性突出问题提出针对性应对措施。
