张家口市公安局

派出所网络舆情处置工作规范

 

 一、派出所职责

快速有效处置涉及辖区的网络敏感舆情，最大限度消除负面影响，确保网络环境清朗。

二、派出所处置要求

（一）综合指挥室舆情管控岗将巡查到的网上敏感信息第一时间上报至值班领导，值班领导联系上报局舆情中心对信息发布者进行身份落地；

（二）对发布者身份已落地的敏感信息，值班领导指派民警上门对信息发布者进行核查，并对信息发布者开展教育敲打、传唤、删帖、签保证书、录承诺视频等工作。

（三）综合指挥室舆情管控岗做好舆情处置相关台帐资料，涉及舆情重点人员的，及时更新管控记录，并搜集汇总违法证据，构成打击标准的及时开展打击处置。

（四）对于媒体记者采访，一律由新闻宣传科按照审核流程，拟定警情通报、新闻通稿、引导口径，对接各类主流新闻媒体适时召开新闻发布会，及时、准确发布官方信息

（五）舆情处置结束后，对每起舆情事件进行复盘总结，及时总结经验，分析不足，完善措施，不断提升舆情处置实战能力。
