张家口市公安局

派出所扬言个人极端警情处置规范

 

一、派出所职责

扬言个人极端类警情处置责任单位为辖区派出所，确保快速出警、及时预防、制止扬言极端人员可能或正在进行的极端行为，保障辖区群众生命财产安全。

二、派出所处置要求

（一）值班领导指派至少两组警力赶赴现场进行处置，同时指令综合指挥室视频巡查岗将警情周边视频监控、车载4G以及4G单兵图像在10分钟内上传至指挥室大屏，确保前后方一体化指挥调度。

（二）现场处置民警确保装备穿戴整齐，在保证自身安全的情况下，及时制止扬言极端人员可能或正在发生的极端行为，若极端人员正在进行危害群众生命财产安全的行为，民警在警告无效的前提下，可以适当使用约束性警械或武器进行制止。

（三）现场处置民警迅速对现场周边群众、店铺是否拍照、录像以及监控情况进行摸排，及时删除相关照片、录像，及时拷贝现场监控视频并删除。

（四）将扬言个人极端人员带回所内制作笔录，构成案件的按照办案流程进行案件办理处置，并要求扬言极端人员书写保证书并签字捺印。未构成案件的，对扬言极端人员进行法制谈话，同时要求书写保证书并签字捺印。

（五）将现场处置音视频及相关笔录、保证书上传至对应警情的处置情况中。

（六）综合指挥室舆情管控岗加强对辖区范围抖音、微博、微信等平台软件的巡查，发现涉事件相关信息，及时上报分县局舆情中心并联系相关发布人员进行删除。

（七）综合指挥室指挥岗及时上报重点警情回溯台帐。

（八）综合指挥室基础管控岗将扬言个人极端人员进行一人一档登记，并流转给社区民警进行上门走访并常态化关注。
