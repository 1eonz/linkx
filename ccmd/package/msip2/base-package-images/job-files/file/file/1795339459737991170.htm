派出所重大突发案事件现场处置工作规范

 

一、派出所职责

对可能危及公共安全、社会稳定，或造成人员伤亡、重大财产损失的各类暴力恐怖案事件、刑事案件、群体性事件、公共安全事故和敏感舆情事件进行及时处置。

二、派出所处置要求

（一）A岗值班领导带领民警规范着装携装，开启执法仪，以最快速度赶赴现场，“135分钟”快速反应控制圈按照规定时限到达，主城区和派出所所在地集镇在5分钟内到达，其他区域以最快速度到达（均以带队民警到达为准）。

（二）B岗值班领导指令综合指挥室视频巡查岗3分钟内完成警情周边现场视频、首波处置警力执法仪或车载视频的调取、投屏工作，持续跟踪现场事态发展，对力量、装备等警务资源和勤务部署做好梯次预编，根据工作需要和现场请求，实时调配力量、装备、物资。

（三）现场警力根据现场情况划定警戒区域，依法限制、禁止人员、车辆通行或停留，依法实施交通管制、现场管制。

（四）迅速抢救伤员，疏散事发现场无关人员，转移现场附近危险物质，制止犯罪，控制犯罪嫌疑人，收缴涉案物品，防止危害扩大。

（五）对嫌疑人、嫌疑车辆逃离现场的，及时上报情指中心开展封控拦截，严防涉案人员、车辆、物品和风险外溢。

（六）对现场周边音视频提取封存、现场画面有效围档、现场群众劝阻带离等工作。

（七）将初步处置情况以及该事件的风险等级评估按照信息报送要求书面上报情指中心，并根据要求进行续报。信息报送首报要快、续报要准、终报要全。

（八）群体性事件处置结束后，对每起群体性事件进行复盘总结，及时总结经验，分析不足，完善措施，不断提升群体性事件处置实战能力。

首报要快，局指挥部应当在接报后20分钟内向诸暨市党委政府和绍兴市局口头报告（电话、短信或浙政钉等形式），并在50分钟内补报正式书面信息。信息材料应说明发生的时间、地点、现场状态、人员伤亡等情况以及现场处置情况，一时难以掌握、仍在核实的，需在首报时说明。

续报要准，续报不晚于首报后2小时，重要情况及时续报；事件持续多日的，要落实专人跟踪盯办，每天至少续报一次。续报时，应准确说明跟进核实掌握的有关情况，包括警情的性质、原因、背景、现场动态及发展趋势、人员伤亡变化、网络舆情以及后续工作措施、工作建议等内容。

终报要全，现场处置结束后，指挥部要跟进做好总体情况汇总，并及时向诸暨市党委政府和绍兴市公安局报告。对敏感案事件、安全事故、自然灾害，要报告最终处置结果；对涉稳风险和涉及人员，要报告化解处置情况、人员防范化解工作及稳控措施落实情况；对重要敏感网络舆情，要报告引导处置情况和工作成效等。
