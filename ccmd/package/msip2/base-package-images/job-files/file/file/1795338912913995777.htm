张家口市公安局

出所群体性事件现场处置工作流程

 一、派出所职责

实现“最短时间发出最准确指令、最优流程完成最高效调度、最快速度最强力量到达现场、最短时间最高效率完成处置”的工作要求。

二、派出所处置要求

（一）A岗值班领导带领民警赶赴现场开展先期处置，尽快查清现场人数、人员身份、行为方式和激烈程度等情况。根据现场情况划定警戒区域，依法限制、禁止人员、车辆通行或停留，依法实施交通管制、现场管制，并围绕中心做好群众疏散、现场秩序维护、外围警戒、交通管控、调查取证、管控无关人员、控制嫌疑人等工作。

（二）现场处置可采取旗语、扩音器喊话等方式对人群进行劝说，对情绪平和的群体，可采用“一字挤压法”将人员劝至社会治理中心；对情绪激动的，可以对群体穿插分离，采用“前面带、两边护、中间劝、后面挡”的方式，将人群带至社会治理中心；对于闹事分子，可采用三人一组快速控制、带离。现场处置时，要灵活运用围档、幕布、雨伞等防拍摄遮挡手段，防止别有用心人员拍照、摄像，制造舆情。

 

（三）B岗值班领导指令综合指挥室视频巡查岗3分钟内完成警情周边现场视频、首波处置警力执法仪或车载视频的调取、投屏工作，持续跟踪现场事态发展，对力量、装备等警务资源和勤务部署做好梯次预编，根据工作需要和现场请求，实时调配力量、装备、物资。

（四）现场处置人员查明事件背景、诉求、聚集群众构成及动向、挑头人员身份及串联活动等情况。

（五）现场处置人员现场处置民警迅速对现场周边群众、店铺是否拍照、录像以及监控情况进行摸排，及时删除相关照片、录像，及时拷贝现场监控视频并删除。

（六）将初步处置情况以及该事件的风险等级评估按照信息报送要求书面上报分县局情指中心，并根据要求进行续报。

（七）综合指挥室舆情管控岗加强对辖区范围抖音、微博、微信等平台软件的巡查，发现涉事件相关信息，及时上报分县局舆情中心并联系相关发布人员进行删除。

（八）群体性事件处置结束后，对每起群体性事件进行复盘总结，及时总结经验，分析不足，完善措施，不断提升群体性事件处置实战能力。
