张家口市公安局

派出所“警医联动”醒酒工作机制

实施方案

 

一、派出所职责

规范醉酒人员的联动处置，及时处置醉酒人员滋扰医疗秩序，实现既保障醉酒人员人身安全和合法权益，又维护良好就医环境和社会治安稳定。

二、派出所处置要求

（一）出警人员必须装备穿戴规范前往处置醉酒警情，出警警力不得少于3人，现场若发生醉酒人员暴力反抗等行为，及时使用警绳或辣椒水等警械装备进行约束或制服；

（二）将醉酒人员送往定点医院治疗，按照“谁送谁负责”的原则做好家属联系查找，同时落实人员看护（管），保障醉酒人员生命安全；

（三）对涉及醉酒人员在医院闹事或其他各类医闹纠纷案事件，根据医院需求配合做好人员信息核查、看护工作；

（四）送医民警负责在医院内放置的“警医联动”情况登记本上将相关信息填写完整并指令接处警队员上报“警医联动”电子表格至分县局情指中心邮箱。

（五）综合指挥室舆情管控岗加强对辖区范围抖音、微博、微信等平台软件的巡查，发现涉事件相关信息，及时上报分县局舆情中心并联系相关发布人员进行删除。
