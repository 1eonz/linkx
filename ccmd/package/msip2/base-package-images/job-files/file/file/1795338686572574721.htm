张家口市公安局

派出所非正常死亡事件工作规范

 一、派出所职责

非正常死亡事件处置责任单位为辖区派出所，主要负责现场保护、调查访问、身源查证、尸体处理、家属告知、社会稳控及档案建立、保存等。 

二、派出所处置要求

（一）值班所领导应迅速带领民警赶赴现场，设置警戒带，对现场进行保护，并对尸体及时进行遮挡；

（二）现场处置民警迅速对现场周边群众、店铺是否拍照、录像以及监控情况进行摸排，及时删除相关照片、录像，及时拷贝现场监控视频并删除。

（三）现场处置民警及时开展调查访问工作,对死者生前活动情况、矛盾情况、关系人员、异常情况进行调查走访；

（四）将初步处置情况以及该事件的风险等级评估按照信息报送要求书面上报情指中心，并根据要求进行续报；

（五）联系刑侦大队根据情指中心指令，及时指派技术人员和法医赶赴现场进行勘验，对尸体进行初检；

（六）综合指挥室舆情管控岗加强对辖区范围抖音、微博、微信等平台软件的巡查，发现涉事件相关信息，及时上报分县局舆情中心并联系相关发布人员进行删除。

（七）保管现场及尸检时所提取的随身物品；

（八）按照办案程序的要求，制作卷宗，“一事一档”留档保存。卷宗一般包括以下内容：接警记录、报警笔录、相关人员调查访问笔录、尸源查找公告、尸体辨认笔录、现场勘验检查笔录、呈请解剖尸体审批表、尸体检验鉴定文书、相关检验鉴定文书、非正常死亡事件调查报告、居民死亡证明、调查终结报告、风险等级评估表等。

三、未知名尸体处置

（一）发现地辖区派出所在报告情指中心的同时，通过实战平台向侦查中心提起人像识别、视频追踪等技术协助。

（二）在现场周围开展调查访问，对报案人、知情人等及时制作询问笔录。

（三）查询比对全省、全国的失踪人员信息。

（四）身份无法查证的，7日内在县级以上新闻媒体刊登认尸启事，启事中须说明尸体发现地点、死者体貌及衣着等特征。

（五）查找到疑似未知名尸体亲属的， 24小时内通知安排辨认，辨认过程及结果应记录在案。对辨认后仍不能明确身源的尸体，在辨认后24小时内采集疑似死者父母或配偶子女、兄弟的血样交刑侦大队，由刑侦大队进行亲缘关系鉴定。

（六）未知名尸体自认尸启事刊登7日后仍无人认领的，3个工作日内将认尸启事复印件、风险等级评估表复印件及“呈请解剖尸体审批表”复印件交法医。尸源查明后，填写“呈请火化尸体审批表”，报局领导审批后，开具“居民死亡证明”，由经办民警会同法医对尸体火化确认签字后，殡仪馆可以按民政部门相关规定处理尸体。
